<h1>X Editor</h1>
<img alt="Python" src="https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54">

The X Editor is a python based simple text editor. For now, it's a really simple project build using Tkinter library, but my expectation is to later work more on it, so I can use my own tool to code an write essays. To use, you'll need Python installed in your computer and that's it.

```
$ git clone https://github.com/arthurgalluccilima/X-Editor.git
´´´
Extract it, cd in to directory and run the command:
```
$ python3 main.py
´´´
