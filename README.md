<h1>X Editor</h1>
The X Editor is a python based simple text editor. For now, it's a really simple project build using Tkinter library, but my expectation is to later work more on it, so I can use my own tool to code an write essays. To use, you'll need Python installed in your computer and that's it.<br/>

```
$ git clone https://github.com/arthurgalluccilima/X-Editor.git
```

Extract it, cd in to directory and run the command:

```
$ python3 main.py
```
